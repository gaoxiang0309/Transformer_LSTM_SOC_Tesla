## 第三轮：融合方案（门控软锚 anchor_mode=gated + 扰动训练）

为解决“硬锚对 Ah 偏移 1:1 跟随、无法纠偏”的问题，做两处配合改动：

**① 可学习门控软锚**（方案三的软锚化）：

```text
mismatch = anchor - q
w = sigmoid( MLP([LSTM末端隐藏; mismatch]) )     # w 初始化≈1（gate_head 偏置+4）
SOC = w * anchor + residual
```

**② 扰动训练**（方案一的数据增强，默认 ramp + 温漂）：

```text
训练集融合时给累计Ah注入电流零偏（label保持作者SOC不变）：
  ramp（默认）= Ah误差 = ∫b(t)dt/3600/C，
                b(t)=b0+tc·(T−25℃)，
                b0∈±perturb_amp(0.05A)，tc∈±perturb_tc(0.001A/℃)  ← 温漂
  step        = 随机时刻 t0 后 Ah += ±perturb_amp
```

| 项目 | 内容 |
|---|---|
| 配置 | `anchor_mode ∈ {hard, soft, gated, dual}`（默认 dual）；`init_lstm_from` warm-start（strict=False）；`perturb_train=true`、`perturb_mode=ramp`、`perturb_amp=0.05`、`perturb_tc=0.001`、`t_norm_low/high`、`perturb_seed` |
| 代码 | `config.py`、`model/lstm_model.py`（gate_head + 四种模式）、`model/train_utils.py`（`_perturb_ah` 温漂 + `make_fused_sequences(perturb=...)` + restore 增加 strict）、`main.py`（warm-start + 训练集注入扰动） |
| 目的 | 结构上让网络能在锚与电压冲突时降权；数据上让网络见过被污染的 Ah、学会用 V/I/T 纠正 |

> 验收沿用 `Transformer_LSTM_SOC_deepseek_对比消融实验/` 的 P0-2 偏移注入：目标从“模型误差≈0.126+|δ|”降到“明显小于 |δ|”。

## 第四轮：方案C（双支路混合 anchor_mode=dual）

在门控软锚基础上，显式引入“电压侧估计 q”作为第二支路，让网络学两路混合比例：

```text
anchor_ah = anchor（积分侧）
anchor_v  = q（电压侧）
mismatch  = anchor_ah - anchor_v
α         = sigmoid( MLP([LSTM末端隐藏; mismatch]) )    # α 初始化≈1
SOC       = α·anchor_ah + (1−α)·anchor_v + residual
```

| 项目 | 内容 |
|---|---|
| 配置 | `anchor_mode=dual`（默认）；`gated`/`hard`/`soft` 保留；`init_lstm_from`/`init_transformer_from` 指向项目内 `pretrained/`（复用基线 Transformer + LSTM，解耦 run/train） |
| 代码 | `model/lstm_model.py`：dual 分支复用 gate_head 输出 α，`(1−α)` 加权到 q |
| 目的 | 相比 gated（只有锚一路、靠残差隐式补电压信息），dual 显式把“积分侧”与“电压侧”两条 SOC 支路都放进输出，网络只需学混合比例，物理含义更清晰 |

## 使用前注意

- 锚依赖 `q[0]` 反推段首 SOC；若段首 q 偏差大，残差需要更大的修正量，建议训练时观察 `train_MSE` 与验证集段首误差。
- C(T) 是用 m80 的 SOC~Ah 斜率拟合的；换电芯/换批次时应重新拟合。
- Ah 特征会显著降低“按安时跟踪 SOC”的难度；若要对照论文的纯 V/I/T 输入，把 `use_ah_feature` 设为 false（需重跑 prepare，且锚/ΔAh 必须同时关闭）。
- 旧基线目录 `baseline1`、`baseline2_1` 的权重配套旧 manifest 与旧输入维度，当前 `test.py` 会拒绝混用。
