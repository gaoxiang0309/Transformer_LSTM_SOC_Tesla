# 论文事实、实现选择与未确定事项

本项目是《Collaborative framework of Transformer and LSTM for enhanced state-of-charge estimation in lithium-ion batteries》的PyTorch方法适配。依据本地论文正文与此前精读记录；没有取得作者完整训练代码、SI窗口表、最终贝叶斯搜索结果。原文定位以PDF页序为准。

## 1. 参数来源逐项对照

| 项目 | 论文能确认的内容 | 本实现 | 身份与原因 |

| 原始数据 | CALCE A123 LFP；DST训练，US06/FUDS测试 | Tesla Model 3 2170 NCA；m80训练、m448-N验证、m1000测试；**只用行车文件**，充电文件排除 | 用户指定的跨电芯、行车SOC适配，不能对照论文数字直接声称复现成功 |

## 2. 数据和窗口的关键未确定项

1. **工况边界与状态**：每个原始MAT文件是一个独立行驶循环，序列按文件切分并标为`source_file`；充电文件整体排除，状态划分依据文件类型而不是电流符号。超过1800 s的长驻车从序列中切掉，短停车保留；冷启动前`L+K-2=358`点无输出。
2. **静置/回馈占比**：只保留行车的三个集合中，静置/短停车约占9%–15%，SOC上升（回馈）约占20%–25%，其余为放电。回馈和短停车属于行车，不再切子状态；总MAE不再被长静置段主导。
3. **采样时间与窗口**：原始文件并非严格1 Hz（6个文件有亚秒级重复突发，共44,271行），已按`Time`重采样到约1 Hz，并在时间差>60 s的缺口处切开；窗口按物理秒定义（300 s/60 s），点数由`sample_interval_s`换算。公司3 s/帧数据对应约100点/20点。
4. **参考SOC与归一化**：使用作者按容量插值得到的SOC，不自行假设由Ah重算得到同一真值；归一化只在m80上拟合，m448-N/m1000有少量越界值按训练边界截断。
5. **电芯独立性**：三颗电芯来自同一台架、同一套测试流程和同一SOC计算方式，跨电芯划分不等于独立车辆/批次验证。
6. **盲测循环**：UDDS/HWFET/LA92/US06属于官方盲测集，本包只有REORDERED/HWCUST/HWGRADE，不能与论文US06/FUDS数字直接对照。
7. **非LFP与非公司BMS**：Tesla 2170为NCA；本项目不具备真实公司BMS基线，不计算或声称相对公司BMS的增强收益。
8. **原论文的其余基线**：当前包含单Transformer与协作模型的对齐比较；未实现GRU、CNN-LSTM或另训三维纯LSTM基线，不声称覆盖原文全部对比。

## 3. 正式实验前需要补齐的证据

确认参考SOC与作者归一化的适用范围；冻结可追溯的split、窗口与参数；如需调参只能使用验证集，不能依据最终测试成绩选窗口/网络；评估多个种子；对放电/回馈/短停车分别报告指标。若要研究样本内q的分布偏差，再在训练集合内部按完整工况做折外预测，不能随机把相邻重叠窗口分折。

Tesla数据的序列边界由原始文件提供，`boundary_status`记录为`source_file`；这不等于已证明文件内部没有拼接或传感器异常。运行通过只说明实现链路可用，不证明已还原论文全部方法或精度。
