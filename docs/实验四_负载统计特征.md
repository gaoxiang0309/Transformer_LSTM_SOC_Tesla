# 实验四：q_Ah 控制组基础上的负载统计特征

## 研究问题

实验三已经加入 60 秒因果 V/I 均值和偏差。实验四检验负载强度与回馈方向组成是否能解释实验三在不同温度、不同 ramp 方向下的剩余误差。

## 输入特征

首轮只追加两个 LSTM 融合特征，Transformer 继续读取 `[V, I, T, Ah]` 并复用 q_Ah 控制组权重。

```text
I_rms_60 = sqrt(mean(I_A^2)) / max(abs(I_low), abs(I_high))
I_pos_ratio_60 = mean(1[I_A > 0])
```

`I_rms_60` 先在物理电流 A 上计算，再用训练侧电流归一化范围的最大绝对值缩放。`I_pos_ratio_60` 是正电流比例，正电流沿用项目中的回馈方向约定。两个特征都使用当前及过去 60 秒，序列首部使用截短历史，片段切换时重置。

## 输入列顺序

```text
[V, I, T, Ah, q, anchor, dAh_short, dAh_long,
 I_rms_60, I_pos_ratio_60]
```

实验四只重新训练 LSTM。前 8 列从 q_Ah 控制组 LSTM warm-start，新增两列使用当前模型初始化。训练阶段仍保留 q_Ah 控制组的 Ah ramp 扰动训练设置，验证和普通测试使用干净输入。验证侧 ramp 评估由 `evaluate_ramp_robustness.py` 单独注入。

## 运行命令

一键完成训练、clean 测试、q_Ah 控制组验证侧 ramp、实验四验证侧 ramp 和配对比较。

```bash
python tools/run_exp4_evaluation.py --device cuda:0
```

评价结果集中写入：

```text
run/train/exp_batch4_qah_loadstats60/analysis/exp4_evaluation/
├── evaluation_manifest.json
├── clean_test/
├── qah_control_ramp_robustness_validation/
├── exp4_ramp_robustness_validation/
└── qah_control_vs_exp4_robustness.csv
```

重复执行会自动创建 `exp4_evaluation_1`、`exp4_evaluation_2` 等新目录，旧评价结果不会被覆盖。已有完整实验四权重时，脚本会自动跳过训练并继续评价。

```bash
python -m unittest discover -s tests -v
python main.py --config configs/exp_batch4_qah_loadstats60.json --device cuda:0
python test.py --run run/train/exp_batch4_qah_loadstats60 --device cuda:0
```

验证侧 ramp 与 q_Ah 控制组使用同样的条件和独立输出目录。

```bash
python tools/evaluate_ramp_robustness.py \
  --run run/train/exp_batch4_qah_loadstats60 \
  --split validation \
  --device cuda:0
```
