## 保持原实现的部分

`attention`、`MultiHeadedAttention`、`PositionwiseFeedForward`、`clones`的可执行代码直接取自原文件，保留其类名和主要中文注释；不是用`nn.TransformerEncoder`替换后声称复用。注意力仍是QK缩放点积、多头拼接及输出投影，FFN仍为Linear–ReLU–Dropout–Linear。

后续教学式风格整理为上述符号补充了中文类/函数文档并统一排版。比较复用计算时需忽略docstring与格式差异；源项目文件本身未修改。其余SOC适配代码将部分嵌套表达式拆成中间变量，模块属性名称保持兼容，已有checkpoint可继续加载。

## 明确改动的部分

| 原模块/行为 | 当前SOC适配 |
|---|---|
| Embeddings处理整数词ID | Linear将连续V/I/T从3维投影到d_model |
| 全局config.device和构造时搬GPU | 构造在CPU，统一由main/model.to(device)搬移；buffer随模型移动 |
| PositionalEncoding固定5000、Variable包装 | 保留正弦公式，按long_window建buffer，移除过时Variable包装，兼容奇数维 |
| 自定义LayerNorm默认std无偏估计 | 明确采用总体方差，与标准LayerNorm的维度归一化含义一致 |
| SublayerConnection为Pre-LN | 支持pre/post，默认post；pre路径保留原来先LN后子层的连接顺序 |
| Encoder末端固定再LN | pre时保留末端LN；post时使用各子层末端LN，不再叠加额外末端LN |
| Encoder+Decoder、词输出Generator | 只保留Encoder；末端表示接Linear输出一个连续SOC |
| Attention mask基于token padding | 固定长度真实历史窗口，无token padding；不能把数值0判为无效输入 |
| Noam优化器、交叉熵、BLEU、beam search | RMSprop、MSE、MAE/RMSE、单步SOC评估 |

LSTM是新增模块，输入为 `[V,I,T,Ah,q,anchor,ΔAh_60,ΔAh_300]`（8 维，按开关拼接），不使用双向LSTM；输出按 `anchor_mode`：`dual`（默认）=`α·anchor+(1−α)·q+残差`，`gated`=`w·anchor+残差`，`hard`=`anchor+残差`，`soft`=纯残差。训练采用两阶段冻结，区别于一个可联合反传的串联网络；这些均已在复现假设中说明。
